# Template báo cáo (dùng với Report Agent - Buổi 4)

> Lưu template này vào phần bối cảnh của Report Agent để mọi báo cáo ra đúng khung công ty.

## Báo cáo tuần

```
BÁO CÁO CÔNG VIỆC TUẦN [số] - THÁNG [tháng]/[năm]
Người báo cáo: [Họ tên] - [Chức danh]

1. KẾT QUẢ TUẦN NÀY
- [Việc đã xong 1]
- [Việc đã xong 2]

2. SỐ LIỆU CHÍNH
- [Chỉ số]: [giá trị] (so với tuần trước: [tăng/giảm])

3. VƯỚNG MẮC
- [Vấn đề + cần hỗ trợ gì]

4. KẾ HOẠCH TUẦN SAU
- [Việc 1]
- [Việc 2]
```

## Email công việc

```
Tiêu đề: [Ngắn, rõ mục đích]

Kính gửi [Anh/Chị/Ông/Bà] [Tên],

[Câu mở nêu lý do email.]

[Nội dung chính, gạch đầu dòng nếu nhiều ý.]

[Câu chốt: đề nghị/hành động mong muốn.]

Trân trọng,
[Họ tên]
[Chức danh - Đơn vị]
[Liên hệ]
```

> Quy tắc CES: email gửi đi không dùng emoji, văn phong chuyên nghiệp.

## Đề xuất / Proposal (khung rút gọn)

```
ĐỀ XUẤT: [Tên]
1. Bối cảnh
2. Vấn đề cần giải quyết
3. Giải pháp đề xuất
4. Lợi ích mang lại
5. Chi phí / nguồn lực
6. Kế hoạch triển khai (mốc thời gian)
```
