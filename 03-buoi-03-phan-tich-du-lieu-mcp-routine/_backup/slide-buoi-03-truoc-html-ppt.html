KIẾN TRÚC QUẢN TRỊ NGỮ CẢNH

Phân Biệt CLAUDE.md Global vs CLAUDE.md Local

Cách tổ chức quy tắc thông minh: Tránh lặp lại chỉ thị nhưng vẫn bảo đảm tính đặc thù

🌐

CLAUDE.md Global (Toàn Cục)

Vị trí: ~/.claude/CLAUDE.md

Áp dụng cho TẤT CẢ các thư mục và dự án trên máy tính của bạn.

  • Vai trò: Hiến pháp chung của công ty & hồ sơ chuyên gia của bạn.
  • Nội dung: Danh tính, xưng hô, văn phong công sở, quy tắc không emoji.
  • Super Rules: Tự động đánh số thứ tự file, cấm xóa file, cấm bịa số.
📁

CLAUDE.md Local (Dự Án / Phòng Ban)

Vị trí: ./CLAUDE.md (Gốc dự án)

Chỉ áp dụng cho duy nhất thư mục dự án đó và các thư mục con.

  • Vai trò: Quy chế riêng dán ở cửa phòng ban đó.
  • Nội dung: Mục đích thư mục, giải nghĩa cấu trúc ngăn kéo con.
  • Quy trình riêng: Báo giá phải có VAT 30 ngày, hợp đồng thanh toán 2 đợt...
Nguyên Tắc Ưu Tiên Giải Quyết Xung Đột Hierarchy Rule

⚡ CỤ THỂ HƠN SẼ THẮNG: Nếu Global ghi "Viết thân thiện, cởi mở", nhưng Local thư mục Hợp đồng ghi "Viết trang trọng, chặt chẽ" ➔ Agent trong thư mục Hợp đồng sẽ chọn văn phong trang trọng!

⚠️ LƯU Ý SỐNG CÒN: File CLAUDE.md chỉ được nạp khi MỞ PHIÊN MỚI. Sửa file xong phải tắt và mở lại phiên chat!

📌 Nhớ: Global = Hiến pháp toàn cục máy | Local = Quy chế nội bộ phòng ban Kiến trúc 2 tầng

Super Rules Trong Global CLAUDE.md: Tự Động Đánh Số File

Chấm dứt hoàn toàn tình trạng cây thư mục lộn xộn và đè mất dữ liệu cũ

🔢

1. Tự Động Đánh Số Thứ Tự

Trước khi tạo bất kỳ file tài liệu/báo cáo nào mới, Agent PHẢI quét thư mục để tìm số thứ tự tiếp theo.

01_ke-hoach-tuan.md
02_bao-cao-doanh-so.pptx
03_so-do-quy-trinh.png
🛡️

2. Bảo Vệ Dữ Liệu & Backup

Không xóa đè! Khi có bản cập nhật thay thế, tự động di chuyển file cũ vào thư mục con _backup/.

  • Bên ngoài duy trì 01 file duy nhất mới nhất.
  • Cấm tuyệt đối chạy lệnh xóa hàng loạt (rm -rf, del *.*).
🎯

3. Chống Bịa Số Liệu

Mọi số liệu tính toán phải trích dẫn rõ nguồn từ dòng nào, file nào.

  • Nếu thiếu số liệu, ghi rõ [Chờ bổ sung].
  • Cấm tự suy diễn, ước lượng hay làm tròn cảm tính.
✨ Kết quả: Mọi file sinh ra tự động xếp lớp ngăn nắp theo thứ tự 01_, 02_, 03_ Super Rules

Bài Toán Token & Giải Pháp Microsoft MarkItDown

Bảo vệ Context Window, tránh hiện tượng Agent bị "ngáo" do ngộp dữ liệu nhị phân

💥

Nỗi Đau: "Cơn Đói Token"

Khi ném trực tiếp file Word (.docx), PDF, Excel (.xlsx) 30 trang vào Agent:

  • Ngốn tới 40.000 – 80.000 tokens do chứa rác định dạng XML ẩn.
  • Context Window bị lấp đầy quá nhanh ➔ Agent bị "lú lẫn", quên chỉ thị ban đầu.
  • Chi phí API tăng vọt, tốc độ phản hồi chậm chạp như rùa bò.
🚀

Giải Pháp: Microsoft MarkItDown

Công cụ mã nguồn mở chính thức của Microsoft (microsoft/markitdown):

-85% TOKEN

Chuyển đổi file gốc sang văn bản Markdown (.md) thuần túy, sạch sẽ, giữ nguyên bảng biểu và cấu trúc phân cấp tiêu đề.

FILE WORD GỐC
32.000 Tokens
Nhiều style, xml rác
QUA MARKITDOWN
⚡ 2 Giây
Lưu file .md tại project
FILE .MD ĐÃ LỌC
1.850 Tokens
Tiết kiệm 94% chi phí!
💡 Bí quyết chuyên gia: Luôn chuyển tài liệu nặng sang Markdown trước khi cho Agent đọc Microsoft MarkItDown
QUY TRÌNH KỸ THUẬT

Quy Trình Vận Hành MarkItDown Trong Dự Án

3 bước tự động hóa chuyển đổi tài liệu lưu trữ cục bộ

Cài Đặt & Cú Pháp Lệnh CLI

# 1. Cài đặt thư viện (1 lần duy nhất)
pip install markitdown

# 2. Chuyển đổi file gốc sang file .md
markitdown tai-lieu-goc/hop-dong.docx -o 03-hop-dong/02_hop-dong.md

Hỗ trợ đa định dạng: .pdf, .docx, .pptx, .xlsx, .html, hình ảnh có chữ (OCR) và file âm thanh!

Cài Vào Quy Tắc CLAUDE.md Phòng Ban

Dặn Agent tự động chạy MarkItDown mỗi khi gặp tài liệu lớn:

"Khi nhận được tài liệu phức tạp (PDF, Word, Excel), hãy tự động chạy lệnh markitdown để chuyển đổi sang file .md đặt trong cùng thư mục dự án trước, sau đó đọc file .md để xử lý nhằm tiết kiệm token."
PROMPT P3: Thực Hành Chuyển Đổi & Tóm Tắt Hợp Đồng

"Trong thư mục tai-lieu-goc/ có file hop-dong-mau-dich-vu.docx. Hãy dùng công cụ markitdown chuyển đổi file này thành markdown lưu tại 03-hop-dong/ theo số thứ tự tiếp theo. Sau đó đọc file markdown vừa tạo và trích xuất: Giá trị hợp đồng, điều khoản thanh toán và mức phạt chậm trả."

Routine: Cho Một Việc Tự Chạy Theo Lịch

  • 1. Chạy lúc nào? Thời điểm cụ thể (8h sáng thứ Hai hàng tuần).

• Kinh doanh: Quét đơn quá hạn 8h sáng thứ Hai ➔ Gợi ý danh sách nhắc nợ.
• Kế toán: Đối soát công nợ ngày 25 hàng tháng ➔ Cảnh báo hóa đơn quá hạn.
• Marketing: Tổng hợp chi phí quảng cáo 17h thứ Sáu ➔ Đo lường CPL, CPA.
• Nhân sự: Lọc hồ sơ ứng viên quá 3 ngày chưa liên hệ vào sáng thứ Hai.
• Hành chính: Bóc tách việc tồn đọng (action items) cuối mỗi ngày làm việc.
