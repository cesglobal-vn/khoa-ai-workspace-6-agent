# Checklist học viên toàn khóa

> In ra hoặc lưu lại. Tích khi hoàn thành mỗi buổi. Đủ 6 dòng là bạn đã làm chủ agent với Claude Code.

## Trước khóa
- [ ] Cài Claude Desktop, đăng nhập tài khoản theo hướng dẫn CES
- [ ] Tạo sẵn 1 thư mục trống làm thư mục dự án của khóa
- [ ] Chuẩn bị 2-3 file công việc thật (1 tài liệu dài, 1 file Excel/CSV, vài ghi chú/email)
- [ ] Tải bộ file demo của khóa về máy
- [ ] Ngồi máy tính, cài Zoom, thử mic

## Sau từng buổi
- [ ] **Buổi 1 (Agent):** Claude Code chạy được, có thư mục dự án + CLAUDE.md, ra lệnh cho agent đọc/sửa file
- [ ] **Buổi 2 (Skill):** Tạo được 1 skill tự động (tóm tắt tài liệu) và dùng lại được
- [ ] **Buổi 3 (MCP):** Cắm được 1 MCP và cho agent đọc dữ liệu, phân tích
- [ ] **Buổi 4 (Subagent):** Tạo được 2 agent chuyên trách (Report, Research) và giao việc
- [ ] **Buổi 5 (Agent Team):** Cho 2-3 agent chạy song song 1 việc, lead tổng hợp
- [ ] **Buổi 6 (Capstone):** Ghép skill + MCP + team chạy 1 quy trình công việc thật

## Sản phẩm cầm về cuối khóa
- [ ] Claude Code chạy trên máy + thư mục dự án + CLAUDE.md của riêng tôi
- [ ] Ít nhất 1 skill tự tạo
- [ ] Ít nhất 1 MCP đã cắm và dùng được
- [ ] 2 subagent chuyên trách
- [ ] 1 agent team biết chia việc song song
- [ ] 1 workflow multi-agent hoàn chỉnh (capstone)
