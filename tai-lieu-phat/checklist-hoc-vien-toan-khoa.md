# Checklist học viên toàn khóa

> In ra hoặc lưu lại. Tích khi hoàn thành mỗi buổi. Đủ 6 dòng là bạn đã có đội 6 AI Agent.

## Trước khóa
- [ ] Có tài khoản AI theo hướng dẫn CES
- [ ] Chuẩn bị 2-3 file công việc thật (1 tài liệu dài, 1 file Excel, vài email)
- [ ] Cài Zoom, ngồi máy tính thao tác theo

## Sau từng buổi
- [ ] **Buổi 1:** Dựng xong Workspace + Orchestrator Agent điều phối
- [ ] **Buổi 2:** Document Agent đọc/tóm tắt/trích ý được tài liệu của tôi
- [ ] **Buổi 3:** Data Analysis Agent phân tích được file Excel của tôi
- [ ] **Buổi 4:** Report Agent soạn được báo cáo/email/đề xuất đúng văn phong
- [ ] **Buổi 5:** Deep Research Agent nghiên cứu được thị trường/đối thủ có kiểm chứng
- [ ] **Buổi 6:** Ghép Multi-Agent chạy 1 quy trình công việc thật (capstone)

## Sản phẩm cầm về cuối khóa
- [ ] 1 AI Workspace cá nhân dùng được hằng ngày
- [ ] 6 AI Agent vận hành
- [ ] Bộ system prompt chuẩn của 6 agent
- [ ] Template báo cáo/email/đề xuất
- [ ] 1 workflow multi-agent hoàn chỉnh (capstone)
